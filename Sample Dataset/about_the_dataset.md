# Sample Dataset

This project runs on Google's public GA4 sample dataset:
`bigquery-public-data.ga4_obfuscated_sample_ecommerce`

An anonymized, real GA4 export from the Google Merchandise Store
(~3 months of ecommerce event data). No download needed — it's
directly queryable in BigQuery. See ../Docs/01_link_ga4_to_bigquery.md
for details.
